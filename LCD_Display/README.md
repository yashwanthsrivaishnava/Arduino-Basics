# 📟 LCD Display – Arduino

## Overview

This project demonstrates how to interface a 16×2 LCD display with an Arduino Uno.

The LCD is used to display text and information generated by the Arduino. This project introduces parallel communication between the Arduino and an LCD using the LiquidCrystal library.

---

## 🎯 Objectives

- Interface a 16×2 LCD with Arduino Uno
- Understand LCD pin configuration
- Display text on an LCD
- Learn to use the LiquidCrystal library
- Understand cursor positioning
- Display information without using the Serial Monitor

| D5 | Digital Pin 4 |
| D6 | Digital Pin 3 |

| K / LED- | GND |

### Potentiometer

| Potentiometer Pin | Connection |
|---|---|
| One Side | 5V |
| Other Side | GND |
| Middle Pin | LCD V0 |

The potentiometer controls the contrast of the LCD.

## ⚙️ Working Principle

A 16×2 LCD can display up to:

```text
16 characters per line
2 lines
```

The Arduino communicates with the LCD using several control and data pins.

The `LiquidCrystal` library provides functions to initialize the LCD, position the cursor, and display text.

In this project, the Arduino displays:

```text
Hello Arduino
LCD Display
```

The LCD can later be used to display sensor readings, messages, warnings, and system status.

---

## 🔄 Working Process

```text
Arduino Uno
     ↓
LCD Initialization
     ↓
Set Cursor Position
     ↓
Send Text Data
     ↓
16×2 LCD
     ↓
Display Information
```
